# SOLID Principles

- Single Responsibility principle
- Open close principle
- Liskov substitution principle
- Interface segregation principle
- Dependency inversion principle

## Single responsibility principle

- Object should only one primary responsibility. All other responsibilities should be move to separate classes.

## Open close principle

- Objects should be open for extension and closed for modification.
- This helps to scale the object with new functionality.

## Liskov substitution principle

- If you have a base class, you should be able to stick a derived class and it should work.
